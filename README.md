# NN-VVC

Implementation and reproduction study of:

**NN-VVC: Versatile Video Coding boosted by self-supervisedly learned image coding for machines**

This repository contains an implementation-oriented reproduction of the NN-VVC research work.

## Project Status

- [x] Development environment
- [ ] VVC baseline
- [ ] LIC
- [ ] IHA
- [ ] IMA
- [ ] F-IMA
- [ ] NN-VVC integration
- [ ] Machine-task evaluation
- [ ] BD-rate / BD-task evaluation
- [ ] Ablation study

## Development

Local development is performed on Windows.

Deep-learning training will be performed on a GPU-enabled cloud environment such as Google Colab.

## Reproducibility

Paper-specified details will be followed as closely as possible. Implementation choices that are not explicitly specified in the paper will be documented separately.
